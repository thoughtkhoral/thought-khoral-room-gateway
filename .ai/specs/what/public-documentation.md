# Room gateway public documentation

## Status

Approved

## Purpose

Explain how operators and contributors build, configure, verify, and safely
integrate the authenticated room gateway.

## Acceptance criteria

- The README identifies the MVP status and gateway responsibility.
- The README lists prerequisites, configuration names, build/test commands,
  security boundaries, compatibility constraints, and the local specification
  index.
- Documentation does not imply that the gateway owns the shared contract or
  production deployment.
- Changes follow the organization issue-first contribution workflow.
